CONSENT WORKFLOW

Controlled authorization

Patients can grant scoped consent to an authorized provider for a registered AI model.

  1. Patient creates consent
  2. Provider and AI model are specified
  3. Consent is recorded on blockchain
  4. Consent can be revoked by the patient
AI AUTHORIZATION

Policy-controlled inference

AI inference is allowed only when the consent, provider, model, purpose, and expiry conditions are valid.

  1. Provider selects a consent
  2. System validates authorization
  3. AI inference is executed
  4. Inference receipt is recorded

SYSTEM

MedChain architecture

Application layer

Python Flask backend with role-based access control and SQLite persistence.

Blockchain layer

Solidity smart contract deployed on the local Hardhat blockchain through Web3.py.

Authorization layer

Consent validity is checked using provider, model, purpose, revocation, and expiry rules.

Audit layer

Model and inference digests provide tamper-evident audit evidence.
